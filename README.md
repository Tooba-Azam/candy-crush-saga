# 🎮 Gameplay

Swap adjacent candies to create matches of **three or more**.

Every successful move can trigger spectacular chain reactions as candies fall, new ones spawn, and powerful special candies unleash devastating effects across the board.

Race against the countdown timer, plan your moves carefully, and aim for the highest score possible.

---

# ✨ Features

## 🍭 Core Gameplay

- Classic Match-3 mechanics
- Intelligent match detection
- Cascading gravity system
- Random board generation
- Guaranteed no starting matches
- Real-time score tracking
- Countdown timer

---

## 💥 Special Candies

| Candy | Ability |
|--------|---------|
| ⚡ Horizontal Striped | Clears an entire row |
| ⚡ Vertical Striped | Clears an entire column |
| 💣 Wrapped Candy | Explodes in a 3×3 area |
| 🌈 Color Bomb | Removes every candy of a chosen color |

Create bigger matches to unlock increasingly powerful candy combinations.

- Smooth swap animations

- Colorful SFML graphics
- Responsive gameplay

# 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Tooba-Azam/candy-crush-saga.git
```

### Requirements

- C++17
- SFML 2.6.1

Compile the project and ensure the **assets** folder remains alongside the executable.

# 🎓 About This Project

This project was developed as my **first-semester programming project** to explore the fundamentals of game development in C++.

While inspired by the classic Candy Crush, every gameplay mechanic, including board generation, match detection, gravity simulation, special candies, animations, and game logic, was implemented from scratch using **C++ and SFML**.
